# Kaveri Mist — Coorg Homestay Website

A full-stack homestay website for **Kaveri Mist**, a four-room homestay on a working coffee estate in Madikeri, Kodagu (Coorg), Karnataka.

Live site: _add your Vercel link here once deployed_

## Features
- Responsive, mobile-first design in a monochrome forest-green palette
- Sections: Hero, About, Rooms, Experiences, Menu (swipeable, category-filtered), Gallery, Location map, Testimonials, Booking form
- Booking form backed by a real API route that saves enquiries to MongoDB
- Built with Next.js App Router + TypeScript + Tailwind CSS

## Tech stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** MongoDB Atlas
- **Icons:** lucide-react
- **Deployment:** Vercel
